## 1. จุดเริ่มต้นและระบบรุ่นแรก — 9 มีนาคม 2569

เริ่มบันทึกโครงการด้วยไฟล์ README แล้วเพิ่มเว็บไซต์หลักในไฟล์ index.html ภายในวันเดียวกัน เว็บไซต์รุ่นแรกมีหน้าล็อกอินครู หน้าเช็คชื่อประจำวัน การเลือกวันที่ รายชื่อนักเรียน ปุ่มกำหนดสถานะ การค้นหาและเพิ่มนักเรียน รวมถึงหน้ารายงานและการส่งออก CSV

ระบบใช้หน้าเว็บ HTML, CSS และ JavaScript ติดต่อบริการ Google Apps Script เพื่อรับส่งข้อมูล ส่วนหน้าตาเว็บใช้ Bootstrap และแบบอักษร Prompt ในรุ่นแรกที่ตรวจพบมีการแยกการใช้งานตามครูประจำชั้นกับผู้ดูแลอยู่แล้ว

ช่วงแรกปรับการล็อกอินให้เหลือการกรอกรหัสผ่าน ลดขั้นตอนที่ผู้ใช้ต้องกรอก และแก้การเปลี่ยนวันที่ให้ดึงสถานะของวันนั้นโดยไม่โหลดรายชื่อทั้งหมดซ้ำ ต่อมาเพิ่มการตั้งค่าปีการศึกษาและภาคเรียน พร้อมแจ้งเตือนเมื่อระบบยังไม่มีข้อมูลปีการศึกษาที่ใช้งาน

## 2. ขยายรายงานและเพิ่มปฏิทิน — 9 มีนาคม 2569 ช่วงบ่าย

หน้ารายงานได้รับการขยายให้มีตัวเลขสรุป กราฟ การเลือกช่วงข้อมูล การแจ้งเตือน การส่งออก Excel และการพิมพ์ โดยปรับรายงานเป็น A4 แนวนอน และเปลี่ยนการเลือกเดือนให้ใช้ปุ่มที่สร้างจากเดือนในข้อมูลจริง

เวลา 14:51 น. มีการเพิ่มหน้าปฏิทิน ทำให้เลือกวันที่แล้วเปิดหน้าต่างเช็คชื่อของวันนั้นได้ ต่อมารองรับวันหยุด วันเรียนชดเชย และการยกเลิกวันพิเศษ จึงเริ่มใช้ปฏิทินเป็นเครื่องมือเชื่อมการดูข้อมูลกับการบันทึกประจำวัน

ในช่วงเดียวกันเพิ่มมุมมองรายบุคคล หมายเหตุรายวัน การตรวจขาดเรียนต่อเนื่อง และเปอร์เซ็นต์รายสัปดาห์ จากนั้นเพิ่มรายงานรายเดือนและรายบุคคล รวมถึงใบแจ้งเตือนสำหรับกรณีการขาดเรียนตามเงื่อนไขของระบบ

## 3. ปรับการใช้งาน สถิติ และโฮมรูม — 9 มีนาคม 2569 ช่วงเย็นถึงค่ำ

เริ่มปรับหน้าจอสำหรับมือถือด้วยการตรึงรายชื่อเมื่อเลื่อนแนวนอน แก้การตัดบรรทัดและการซ้อนของคอลัมน์ รวมถึงจัดแถบเมนูใหม่ เพิ่มสถานะ “ป่วย” ให้แยกจากการลา และปรับรายการนักเรียนเป็นหนึ่งคอลัมน์

มีการทดลองเปลี่ยนโครงหน้าให้แสดงภาพรวมเป็นหลักสองช่วง แล้วนำโครงหน้าเดิมกลับมาในครั้งถัดไป ก่อนพัฒนาหน้าสถิติภาพรวมที่เปิดจากหน้าล็อกอินได้อย่างชัดเจน การทดลองเหล่านี้อยู่ในประวัติโค้ด แต่ไม่ควรนับเป็นความสามารถที่เพิ่มสะสมทั้งหมด

ต่อมาแก้ขั้นตอนแสดงสถานะกำลังโหลดหลังล็อกอิน เพิ่มรายงานเช็คชื่อประจำวันแบบจัดหน้าและบันทึกเป็น PNG เวลา 22:40 น. เพิ่มการบันทึกกิจกรรมโฮมรูม พร้อมหัวข้อ หมายเหตุ และรายงานรายวัน/รายเดือน จากนั้นปรับให้ดึงบันทึกโฮมรูมเดิมมาแก้ไข รวมทั้งแก้ลำดับวัน ชื่อเดือน และปีในรายงาน

## 4. ควบคุมวันเรียนและล้างข้อมูล — 10 มีนาคม 2569

## 5. ใช้ปฏิทินเป็นหน้าหลักและขยายสรุปผล — 12 มีนาคม 2569

ปรับโครงระบบให้หน้าเช็คชื่อและปฏิทินเป็นศูนย์กลางการทำงาน เพิ่มแป้นตัวเลขสำหรับเข้าสู่ระบบด้วย PIN ปรับการเลือกปีการศึกษาและภาคเรียน กำหนดวันเปิด–ปิดเทอม และคำนวณจำนวนวันเรียน

พัฒนางานเพิ่มและย้ายนักเรียน รวมถึงการย้ายกลับเข้า เพิ่มหน้าสรุปรายเทอม/รายปีและพิมพ์สรุป รองรับการเลือกปีการศึกษาเดิมหรือเพิ่มปีใหม่ และเพิ่มการแจ้งเตือนวันที่ยังไม่มีการเช็คชื่อในเดือน

ช่วงท้ายของวันปรับเงื่อนไขให้ปฏิทินและการแจ้งเตือนอิงช่วงเปิด–ปิดเทอม แก้การรับมือเมื่อยังไม่มีการตั้งค่าช่วงวัน และเติมส่วนคำนวณ/แสดงปฏิทินให้ครบหลังแก้โครงสร้าง

## 7. รอบปรับปรุงจากการใช้งานจริง — ก่อนบันทึกชุดใหญ่วันที่ 20 กันยายน 2569

ผู้พัฒนาแสดงปัญหาจากหน้าจอจริงและขอปรับทีละส่วน โดยเริ่มจากปุ่มสถานะที่อยู่ไม่ตรงแนวกันตามความยาวชื่อนักเรียน และขอดูตัวอย่างก่อนนำขึ้นเว็บไซต์จริง

ลำดับคำขอและการปรับในรอบนี้มีดังนี้:

1. จัดเลขที่ ชื่อ และปุ่มสถานะให้เป็นคอลัมน์และแถวที่สม่ำเสมอ
2. สร้างตัวอย่างในเครื่อง เพื่อเปิดดูและปรับแก้ก่อนเผยแพร่
3. ปรับรูปแบบบนมือถือให้ชื่ออ่านง่าย ปุ่มกดสะดวก และจัดพื้นที่ส่วนบันทึกให้ชัดเจน
4. ทบทวนการใช้งานตั้งแต่หน้าล็อกอิน การนำทาง และหน้าปฏิทิน
5. ลดความแน่นของข้อมูลในปฏิทิน และจัดเครื่องมือเพิ่มเติมให้กินพื้นที่น้อยลง
6. นำโฮมรูมมาเป็นอีกแท็บหนึ่งบนหน้าปฏิทิน เลือกวันเพื่อเปิดบันทึกได้
7. ตรวจฟอนต์ ขนาดข้อความ ช่องกรอก และขนาดปุ่มสำหรับมือถือ
8. ปรับการแจ้งเตือนข้อมูลที่ยังไม่บันทึก การป้องกันกดบันทึกซ้ำ และการรับมือเมื่อบันทึกไม่สำเร็จ
9. เมื่อผู้ใช้อนุญาต จึงส่งโค้ดขึ้น GitHub และตรวจผลบนเว็บไซต์จริง

รายละเอียดในบทสนทนาช่วงนี้ไม่ได้มีเวลาบันทึกแยกทุกครั้ง จึงไม่กำหนดวันและเวลาของแต่ละข้อขึ้นเอง โค้ดหลายส่วนถูกรวมไว้ในการบันทึกชุด a913bdb เวลา 00:48 น. วันที่ 20 กันยายน 2569

หน้าตรวจและภาพสรุปใช้สองสถานะหลัก คือ “เช็คชื่อแล้ว” และ “ยังไม่เช็คชื่อ” วันที่ลงไม่ครบจะอยู่ฝั่ง “ยังไม่เช็คชื่อ” พร้อมรายละเอียดจำนวนที่ลงแล้ว ไม่ใช้คำว่าเช็คชื่อแล้วแทนความหมายว่ามาเรียนครบทุกคน

### 12:12 น. — แชร์รายงานเช็คชื่อรายวันไป LINE

เพิ่มปุ่ม “แชร์ภาพ / LINE” ในรายงานเช็คชื่อประจำวัน เตรียมภาพเต็มหน้าล่วงหน้าเพื่อให้พร้อมแชร์ และคงปุ่มบันทึก PNG เมื่ออุปกรณ์ไม่รองรับการแชร์ไฟล์โดยตรง

การทำงานนี้เป็นการเปิดเมนูแชร์ของอุปกรณ์ ผู้ใช้เลือก LINE และกลุ่มปลายทางเอง ไม่ใช่บอตส่งอัตโนมัติเข้ากลุ่ม และความพร้อมของตัวเลือก LINE ขึ้นกับอุปกรณ์และแอปที่ติดตั้ง

### 12:16 น. — ลดปุ่มในหน้าเช็คชื่อ

นำปุ่ม “บันทึกโฮมรูม” และ “พิมพ์โฮมรูม” ออกจากหน้าต่างเช็คชื่อ เพื่อให้หน้านี้เน้นการลงสถานะและบันทึก ส่วนโฮมรูมยังเข้าได้จากแท็บบนปฏิทินและคำถามหลังบันทึกเช็คชื่อสำเร็จ
